What to do with what is already here
What WorkBox does

WorkBox reads your clipboard in the background, about every 2.5 seconds, so that a text copied anywhere — not only in the browser — lands in your history. Everything stays on this device, nothing is sent to a server, and you can exclude sites or encrypt the texts with a password. No account, no analytics, no advertising.

Save what I copyOff means WorkBox stops reading the clipboard altogether. The Paste button still works, because that is you asking for it.
Clipboard encryption

Your saved texts are encrypted with a key that only your password can open. That key is never written to disk: after a browser restart, one unlock covers the whole session.

Private sites

WorkBox saves nothing you copy on these sites. Handy for banks, webmail or password managers.

Trusted sites

ℹ️ WorkBox detects
🔗 Link: URLs. Once you have copied 3 links from the same site, it gets its own filter with its icon and name
🎥 Video: .mp4, .webm, .mov + YouTube/TikTok links
🖼️ Image: .png, .jpg, .gif, .webp, .svg
🎨 Color: Hex, RGB, RGBA, HSL
🔐 API Key: OpenAI, GitHub, Slack, Google, AWS, Stripe, JWT...
🔒 Private: Emails, phone numbers, passwords, API keys
✉️ Email: Email addresses
📞 Phone: Local/international numbers
🔑 Password: Complex text (8-64 characters)
📅 Date: Dates and times
💰 Price: Currency amounts (€, $, £...)
💻 Code: JS, Python, Java/C#, HTML, CSS, SQL, Shell, JSON, YAML
🔢 Number: Digits only
📍 Address: Postal addresses
📝 Text: Basic (default category)
🗜️ Supported formats
🖼️ JPG / JPEG, PNG, WEBP, GIF, BMP: recompressed in their original format by default (or kept as-is if it wouldn't help, or if a transparent background is detected). Enable "Convert to JPEG when possible" to allow converting to JPEG for extra savings.
✒️ SVG: optimized directly (comments, metadata and extra whitespace stripped) — stays vector, never rasterized
🎮 TGA (Truevision): format used in video games and 3D rendering, decoded and compressed
💾 PCX: legacy format from DOS-era software, decoded and compressed
🧮 PPM / PGM / PBM (Netpbm): very simple raw format used in programming/research, decoded and compressed
🚫 Not supported: camera RAW, EXR/DPX, FITS — specialized formats that would need decoders too heavy for a "lite" extension
